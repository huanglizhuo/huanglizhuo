FuseBar puts system status, running apps, input sources, and project shortcuts into one compact menu bar panel. Hide the Dock to give your editor more room, and use FuseBar to get back to everything else.

## What it does

- A status ring shows battery, network or sound output, and volume
- Side menus cover battery, Wi-Fi, Bluetooth, and sound
- Search opens apps by name, initials, or pinyin, and also switches devices, input sources, projects, and System Settings panes
- A coding layout keeps each project's folder, preview, and repository one click away

## Download

Get the latest universal build from [GitHub Releases](https://github.com/huanglizhuo/FuseBar/releases/latest). It is signed with Developer ID and notarized by Apple. FuseBar is not on the Mac App Store.
